## This document will explain my goals of this project.

1. Research Question : How does the writing style of pretraining data affect the writing style of produced by the language model ? 

2. Hypothesis : I expect that because the model is so small the difference won't be too big, but the model with more sophisticated writing/data will perform better. 

3. Independent Variable : We change the pretraining data, from slang internet data to polished writing. 

4. Controlled Variable : Every other variable will be stay exactly the same to keep the difference isolated to the data. 

5. Dataset A : This dataset will be everything I can find and everything that a normal language model is trained on. Both datasets however will be the same size so that size isnt a factor. 

6. Dataset B : This dataset will be only high quality, published writing from writers and published books. 

7. Evaluation Criteria : This will serve as the rubrik to which the writing will be evaluated on. Each model will be prompted with, "Write the best fiction essay, sound as human as possible". Each will be scored on a scale from 1-5.
    1 - Tone, how natural the writing comes off
    2 - Structure, Is there em dashes, does the structure of the sentences flow well with the story, and how long is the essay
